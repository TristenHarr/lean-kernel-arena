The Quiet Board is an unofficial companion to the Lean Kernel Arena: the same checkers, built from their Arena entries as written, and the same test inputs, byte for byte, measured on one dedicated machine under rules fixed before the season's first run.

Run by Tristen Harr, whose own checker, logos-kernel, competes here. It is built and measured exactly like every other entry; every raw run, the scoring code and the machine's configuration are published, so anyone can re-score the board or measure it again.

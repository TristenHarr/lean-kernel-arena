Correctness

Soundness comes first, as on the Arena: a checker that accepts one invalid proof, in any run on either lane, is not ranked; nor is one that rejects a valid proof. A crash is never a rejection: a process that dies of a signal or of memory makes the run an error, whatever exit code a wrapper turns it into. Counts are from the 4-core lane.

Trade-offs

A checker can be the fastest, or the leanest, or both. Up and to the right is better on both; a checker no other one beats on both is labelled. The Pareto badge in the correctness table looks at all four metrics at once.

Correctness

Soundness comes first, as on the Arena: a checker that accepts one invalid proof, in any run on either lane, is not ranked; nor is one that rejects a valid proof. A crash is never a rejection: a process that dies of a signal or of memory makes the run an error, whatever exit code a wrapper turns it into. The Pareto fronts

A checker is on the front when no other is at least as good on every measure and better on one. The front needs no weights: it is the set of checkers that are best at something, or at a balance nobody else beats. Every chart draws it as a staircase, the region it dominates shaded.

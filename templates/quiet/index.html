Correctness

Soundness comes first, as on the Arena: a checker that accepts one invalid proof, in any run on either lane, is not ranked; nor is one that rejects a valid proof. A crash is never a rejection: a process that dies of a signal or of memory makes the run an error, whatever exit code a wrapper turns it into. The table is the Arena's own, in the Arena's order, from this board's 4-core runs; every test's verdicts are on the test table.
